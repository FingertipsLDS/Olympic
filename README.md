# 健身日记 📱💪

一个可安装到安卓手机的健身打卡 PWA（渐进式网页应用）。记录体重、运动项目、时长和照片，数据全部保存在手机本地，支持离线使用。

## 功能一览

- **记录运动**：项目（篮球、乒乓球、骑车、跑步、游泳、健身等 9 个内置项目）、时长、强度、备注、照片（拍照 / 相册，最多 6 张）
- **自定义项目**：在「我的 → 运动项目管理」中添加 / 编辑 / 删除项目，可选 36 种图标和 10 种颜色
- **记录体重**：日期、体重、备注、照片（最多 3 张），查看趋势折线图与目标线
- **打卡日历**：月度视图，有运动（绿点）/ 体重（黄点）记录的日期自动打点，点任意日期查看并添加当天记录
- **统计**：累计次数、累计时长、本月次数、连续打卡天数、近 8 周时长柱状图、项目时长分布
- **目标**：目标体重 + 每周打卡天数目标，首页显示本周进度
- **深色 / 浅色 / 跟随系统** 三种主题
- **数据备份**：一键导出含照片的 JSON 备份文件，可随时导入恢复

## 如何在安卓手机上安装使用

PWA 的"安装"依赖 HTTPS（或 localhost），推荐下面任意一种方式：

### 方式一：免费托管后安装（推荐，可离线使用）

任选一个免费托管平台，把本文件夹里的内容全部上传：

- **Netlify Drop**：打开 <https://app.netlify.com/drop>，注册登录后把整个文件夹拖进去，几秒后得到一个 `https://xxx.netlify.app` 网址
- **GitHub Pages**：新建仓库 → 网页上传本文件夹所有文件（`Add file → Upload files`）→ 仓库 `Settings → Pages` 选择 `main` 分支部署，得到 `https://用户名.github.io/仓库名/` 网址

然后用**手机浏览器**（Chrome / Edge / 华为浏览器等）打开这个网址：

1. 第一次打开后，浏览器地址栏或菜单里会出现「安装应用 / 添加到主屏幕」
2. 点「安装」，桌面就会出现「健身日记」图标
3. 之后点击图标即可像原生 App 一样全屏使用，断网也能打开

> iOS Safari 也可以：打开网址 → 分享按钮 → 「添加到主屏幕」。

### 方式二：本地局域网预览（临时体验，不能离线安装）

1. 在电脑上双击运行 `start.sh`（或在终端执行 `python3 -m http.server 8000`）
2. 手机连接与电脑**同一个 WiFi**
3. 手机浏览器打开脚本显示的 `http://电脑IP:8000` 地址

> 局域网 IP 不是 HTTPS 环境，只能预览功能，无法注册离线缓存；正式使用请用方式一。

## 使用说明

- **今天**页：顶部显示今日概况和连续打卡天数；「记录运动」「记录体重」按钮打卡；绿色悬浮按钮在任何页面快速打卡
- **日历**页：左右箭头切换月份，点日期查看当天所有记录，绿点 = 有运动、黄点 = 有体重
- **统计**页：查看趋势和分布，可切换时间范围
- **我的**页：设置目标、主题、管理项目、备份数据
- 照片拍摄后会自动压缩，不占太多空间；所有数据都存在手机浏览器本地，卸载应用或清除浏览器数据前请先「导出备份」

## 文件结构

```
index.html            应用入口
manifest.webmanifest  PWA 安装清单
sw.js                 Service Worker 离线缓存
css/style.css         全部样式（含深色模式）
js/app.js             入口与导航
js/db.js              IndexedDB 数据层
js/utils.js           工具函数
js/charts.js          体重趋势 SVG 图表
js/forms.js           打卡/体重/项目表单弹窗
js/pages.js           四个页面渲染
js/backup.js          备份/导入/清除
icons/                应用图标
start.sh              本地预览脚本
scripts/gen_icons.py  图标生成脚本
```

## 修改代码后如何更新

改了任何文件后，需要把 `sw.js` 顶部的 `CACHE = 'fitdiary-v1'` 改成 `fitdiary-v2`（依次递增），重新部署后手机端才会拉取新版本。否则手机可能一直用旧缓存。
